# Project Glossary

A transcription version is an immutable ordered list of mathematical lines. An evaluation records the grading-engine version and the source transcription version. FIRST_ERROR is the first provably inequivalent step; PROPAGATED_ERROR is a valid local continuation of that error. UNSUPPORTED means the engine cannot verify the domain. FINALIZED records a teacher-released result, not an assertion that an automated answer is correct. A demo space isolates one visitor’s fictional teacher and student accounts.
