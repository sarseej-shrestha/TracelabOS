# Adaptive Learning Engine

`bkt-reviewed-1` persists provisional estimates for each classroom/student/skill. A teacher's correct/needs_practice decision adds one Boolean observation per submission. Repeated reviews replace it; requires_review excludes it. Automatic evaluation or unconfirmed OCR never adds evidence. Evidence references the latest immutable review and original evaluation; all previous reviews/evaluations remain preserved. A transaction writes review, evidence, recomputed estimate, state and release event together.

Recomputation orders observations by original evaluation timestamp and submission ID, so correcting an older review does not move that attempt to the end. Versioned estimates are derived state; historical versions are not overwritten by a new model version. Prior .2, learning .1, guess .25 and slip .1 are explicitly provisional and unfitted. The standard model assumes no forgetting. Readiness requires at least three observations and probability .85; sparse evidence remains labeled insufficient. No calibrated probability or educational improvement is claimed.

`rules-0.2.0` validates the curriculum DAG and searches transitive prerequisites in deterministic order. It uses only ready estimates from the current classroom. Unknown work continues to request teacher review. Student/teacher submission views show evidence counts and an expandable explanation. The authorized classroom mastery endpoint returns the current model/version/parameters. Student scopes cannot inspect peers and teachers cannot inspect other classrooms.

Migration 0004 seeds 24 skills and their prerequisite edges, with evidence and versioned estimate tables. Existing pre-migration reviews remain intact but are not automatically backfilled; they enter the projection when reviewed again. TASK-0022B delivers targeted practice: an owner teacher with a latest needs_practice review publishes one intro-difficulty question for that student. A deterministic seed and the complete generated snapshot are retained. A recommendations row preserves source submission, review/evaluation IDs, selected skill, rules version/reason and the current mastery snapshot. Repeated requests return the existing assignment, even if the original review is later corrected; they never rewrite historical intervention evidence. Further practice can be assigned from the reviewed child submission. Teacher-directed practice after unsupported automatic work uses the original assigned skill and its prerequisites, not unproved error labels. Historical-evidence backfill and strategy comparisons remain pending.

It selects the evaluation existing at review time, orders attempts by original evaluation timestamp/submission ID, preserves old model versions and immutable intervention snapshots, and does nothing on an unchanged repeat. Invalid historical input blocks apply. The local preserved demo has been backfilled with verified source-table preservation. See [[Local-Development]]. The Engineering workspace includes a browser-only learning laboratory. Fictional outcomes call the same pure production estimator, with a twenty-outcome bound, undo/reset, an inspectable pre-response prediction/post-response belief table, and an accessible belief trace. It performs no API mutations and clears when unmounted. Prediction metrics are imported from the published synthetic report at build time; scenario selection never reruns or fabricates an experiment. Belief, response prediction and readiness are explicitly distinguished; provisional assumptions and reproduction links remain visible.
