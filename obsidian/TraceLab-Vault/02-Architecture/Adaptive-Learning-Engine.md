# Adaptive Learning Engine

`bkt-reviewed-1` persists provisional estimates for each classroom/student/skill. A teacher's correct/needs_practice decision adds one Boolean observation per submission. Repeated reviews replace it; requires_review excludes it. Automatic evaluation or unconfirmed OCR never adds evidence. Evidence references the latest immutable review and original evaluation; all previous reviews/evaluations remain preserved. A transaction writes review, evidence, recomputed estimate, state and release event together.

Recomputation orders observations by original evaluation timestamp and submission ID, so correcting an older review does not move that attempt to the end. Versioned estimates are derived state; historical versions are not overwritten by a new model version. Prior .2, learning .1, guess .25 and slip .1 are explicitly provisional and unfitted. The standard model assumes no forgetting. Readiness requires at least three observations and probability .85; sparse evidence remains labeled insufficient. No calibrated probability or educational improvement is claimed.

`rules-0.2.0` validates the curriculum DAG and searches transitive prerequisites in deterministic order. It uses only ready estimates from the current classroom. Unknown work continues to request teacher review. Student/teacher submission views show evidence counts and an expandable explanation. The authorized classroom mastery endpoint returns the current model/version/parameters. Student scopes cannot inspect peers and teachers cannot inspect other classrooms.
