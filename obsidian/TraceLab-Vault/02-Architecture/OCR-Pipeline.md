# OCR Pipeline

Photograph capture, crop/rotation, decoded private storage and mandatory student confirmation are implemented. The experimental local Pix2Text service is now connected through durable database jobs. The API authorizes ownership, checks image/version, applies persisted quotas, enqueues and returns 202. A separate Node worker acquires a bounded lease, verifies the image hash, performs inference outside the database transaction and appends structured output plus an editable transcription version. Successful extraction never grades automatically. Student edits remain separate from the original output.

Ninety-second leases recover interrupted workers; claim tokens reject late results. Provider failures/timeouts retry at most three times with backoff. Invalid output or exhausted attempts leads to EXTRACTION_FAILED. Manual-entry cancellation preserves the previous transcription. Events contain job/version/status metadata, never photographs. PostgreSQL migration 0003 and the SQLite upgrade preserve existing rows. The source importer includes jobs and tolerates pre-job databases.

The Python service proposes bounded single-column pixel regions and returns measured boxes, no confidence. General MathWriting pilot accuracy is poor; this remains an experimental correction aid. The UI now polls processing state, preserves drafts before extraction, cancels into manual entry, displays original machine output and requires explicit confirmation after edits. Teacher inspection retains that original output. Targeted photographed-work acceptance remains pending. No Cloudflare queue consumer or live cloud inference is claimed. Operational commands: services/ocr-worker/README.md.

## Hosted adapter contract

The Workers AI Mistral adapter is implemented but not activated. It fixes the requested model alias, 512-token output and 384,000-byte encoded-image input bound, and accepts the two measured provider response shapes. A strict 1–24-line contract rejects empty/overlong lines, control characters, extra grading fields and malformed JSON; it never repairs recognition. Optional provenance preserves the requested alias, provider-returned model identity when present, and original response text or structured lines. Adapter version is not an immutable weight version. No bounding boxes or confidence values are invented. QUOTA_EXHAUSTED is terminal with manual fallback, including HTTP 429; timeouts/ordinary transport errors retain existing bounded retries. Persistent cloud inference limits and a private transport are required before activation.
