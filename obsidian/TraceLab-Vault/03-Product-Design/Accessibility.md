# Accessibility

Implemented practices include landmarks, skip link, visible focus outlines, explicit input labels, live status, alert errors, text outcome labels, reduced-motion CSS, and responsive layouts. Plain-text mathematics is readable but lacks rich MathML support. Playwright/axe checks are configured but did not run because the local server could not bind a port. WCAG 2.2 AA conformance is not claimed; screen-reader, keyboard, contrast, zoom, and touch-target review remains necessary.
