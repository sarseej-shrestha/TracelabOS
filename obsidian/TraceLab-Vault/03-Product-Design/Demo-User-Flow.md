# Demo User Flow

The landing button provisions an isolated fictional teacher/student pair, one classroom, and the distribution assignment. The student can load a clearly labeled correct or incorrect transcription example, confirm it, and inspect actual engine feedback. Switching role stays within that demo space. Live extraction is visibly unavailable. Fraction/ambiguous-OCR guided scenarios and a real handwritten benchmark are not yet complete.
