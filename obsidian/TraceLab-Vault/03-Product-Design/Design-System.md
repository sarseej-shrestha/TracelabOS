# Design System

Muted green, warm off-white, amber for reasoning errors, serif mathematical/large headings, system sans-serif controls. Controls use borders and explicit outcome text, not color alone. Shared CSS lives in apps/web/app/globals.css. UI emphasizes original work and explanations rather than decorative charts. Typography uses local fonts and makes no network font request.
