# Student User Flow

Enter an isolated demo or local fictional account → join classroom → open assignment → optionally attach a photo → enter or correct mathematical lines → save draft → explicitly confirm → inspect released reasoning feedback. Reordering/removing lines resets consent. Selecting an unsaved photo disables confirmation until the photo is saved. Unsupported input asks for review rather than assigning an incorrect grade. Remediation attempts and mastery progress remain pending.
