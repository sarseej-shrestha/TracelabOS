# Student User Flow

Enter an isolated demo or local fictional account → join classroom → open assignment → optionally attach a photo → enter or correct mathematical lines → save draft → explicitly confirm → inspect released reasoning feedback. Reordering/removing lines resets consent. Selecting an unsaved photo disables confirmation until the photo is saved. Unsupported input asks for review rather than assigning an incorrect grade. Released work shows reviewed classroom skill progress. After the teacher assigns focused practice, open it from the reviewed submission or assignment list, solve/correct/confirm it through the same workflow, and receive a subsequent teacher review. Estimates are provisional and practice is visible only to the target student and owning teacher.
