# Teacher User Flow

Authenticate as a local teacher → create classroom → share enrollment code → preview a seeded skill question → publish assignment with feedback policy and optional due date → inspect submissions → inspect private photo and confirmed steps → append review → release feedback. The original automatic evaluation is preserved. Dashboard metrics use actual records; no fictional operational statistics are seeded.

Related: [[00-START-HERE]] · [[Current-State]]

After recording needs_practice, select Assign recommended practice. The application chooses an unmet prerequisite using reviewed classroom evidence and publishes one intro question for that student. Inspect the resulting linked title/explanation; repeated clicks cannot create duplicate follow-ups. The student's completed practice enters the normal submission queue and can receive its own review. Original reviews, automatic evaluations and intervention provenance remain preserved.
