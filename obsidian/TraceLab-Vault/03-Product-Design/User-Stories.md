# User Stories

As a student, I can correct a draft without silently changing a confirmed result. As a teacher, I can override an automatic result without erasing its provenance. As a visitor, I can explore both roles without exposing another visitor’s classroom. As a maintainer, I can reproduce generated problems from seed, difficulty, and template version. Integration tests cover these API behaviors; browser evidence remains pending.
