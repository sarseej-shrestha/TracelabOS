# Fractions

Implemented equivalent-fraction reduction and unlike-denominator addition use exact rational reference answers. For 1/2+1/3, a valid path is 3/6+2/6 → 5/6. Adding denominators is classified only when the observed wrong value matches that specific rule. Subtraction, multiplication, and division expressions parse, but dedicated curriculum templates and misconception coverage are pending. Fraction bars and number lines remain pending.
