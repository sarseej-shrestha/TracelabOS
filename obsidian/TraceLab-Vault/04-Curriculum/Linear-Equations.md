# Linear Equations

Implemented one-step and distribution templates. The reference example 3(x-2)=15 → 3x-6=15 → 3x=21 → x=7 is valid. The incorrect 3x-2=15 is recognized as partial distribution; later x=17/3 is consistent with that wrong equation. Constant divisions are supported; variable denominators and nonlinear operations request review. Variables on both sides normalize when affine, but dedicated teaching templates remain pending.
