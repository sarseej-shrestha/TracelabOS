# Phase 3 Computer Vision

Acceptance remains a genuine handwritten photograph securely uploaded, actually transcribed, corrected, confirmed and evaluated. Implemented: private normalized upload; two real-model pilot experiments with pinned input/model provenance; authenticated experimental Pix2Text inference; durable database queue, leases, retry/cancel/quotas; browser processing status, editable correction and original-output inspection; mandatory confirmation and preserved teacher review.

Eight browser tests pass using a deterministic HTTP provider fixture; separate actual-model API and Chromium smokes also pass. Actual research input was rendered human pen strokes, not a camera photograph. The measured pilot was poor (3/72 exact for Pix2Text), so production model selection and targeted photographed-work acceptance are NOT complete. Hosted inference and cloud infrastructure remain pending credentials. Manual entry continues as the reliable fallback. See [[OCR-Benchmark-Results]] and [[Test-Results]].
